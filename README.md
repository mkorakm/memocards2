# MemoCards — вёрстка (Flexbox + SASS)

Страницы: **Главная, Колоды, Соревнования, Профиль, Вход, Регистрация**, а также экраны
состояний: ошибки форм, «Аккаунт создан», страница 404. Адаптивно: телефон / планшет
(от 700px) / компьютер (от 1000px). Три цветовые темы.

## Страницы

| Файл | Что это |
|---|---|
| `index.html` | Главная |
| `decks.html`, `competitions.html` | Колоды, Соревнования (каталог с фильтром и сортировкой) |

| `chat.html` | Активный чат с историей (прокрутка), поиском, вложениями, быстрыми ответами |

| `chat-typing.html` | Индикатор «оператор печатает» |
| `chat-attachments.html` | Вложения: превью, загрузка, ошибки (большой файл, неверный формат) |
| `chat-offline.html` | Оператор не в сети |
| `chat-error.html` | Потеря соединения и неотправленное сообщение |

## Сообщения об ошибках пользователя

- ошибка под полем: красная рамка, иконка «!» и пояснение, что именно не так;
- общий баннер над формой («Не удалось создать аккаунт — исправьте N ошибок»);
- всплывающие уведомления (toast): успех, ошибка, информация. Пример: гость нажимает
  «Участвовать» и видит «Чтобы участвовать в соревновании, войдите в аккаунт»;
- ошибка исчезает, когда пользователь начинает исправлять поле, фокус переходит на первое
  неверное поле; есть страница 404.

Проверки регистрации: имя не короче 2 символов, корректный email, email не занят, пароль не короче
8 символов и содержит цифру, пароли совпадают, принято соглашение. Вход: пустые поля, формат
email, аккаунт не найден, неверный пароль.

> Пользователи хранятся в `localStorage` браузера — это учебная демонстрация фронтенда.
> В реальном приложении регистрацию и проверку пароля выполняет сервер.

## Чат технической поддержки

Состав интерфейса (по рекомендациям): многострочное поле ввода с подсказкой, кнопка отправки
(иконка-самолётик, отключена при пустом поле), пузыри сообщений разных цветов для пользователя и
оператора, аватары со статусом онлайн/офлайн, индикатор набора, время и статус доставки
(✓ отправлено, ✓✓ доставлено), история с прокруткой и поиском, системные сообщения, вложения
с превью и проверкой (PNG, JPG, PDF, TXT, ZIP до 5 МБ), быстрые ответы, форма оценки качества.

Клавиши: Enter — отправить, Shift+Enter — новая строка. Ответы «оператора» имитируются на
фронтенде (учебный прототип); в реальном приложении сообщения передаются на сервер.

## Структура

```
memocards/
├── *.html
├── scss/                 # исходники SASS
│   ├── _variables.scss     # размеры; цвета как ссылки на CSS-переменные
│   ├── _themes.scss        # цветовые темы (rose / dark / ocean)
│   ├── _mixins.scss        # flex(), card-surface, tag-color, cols
│   ├── _base.scss          # сброс, шапка, кнопки, нижняя панель
│   ├── _components.scss    # hero, карточки, теги, ряды и сетки
│   ├── _catalog.scss       # выпадающие списки
│   ├── _forms.scss         # поля формы, ошибки, баннеры
│   ├── _feedback.scss      # toast, экраны состояний
│   ├── _profile.scss       # профиль, выбор темы, меню
│   ├── _chat.scss          # чат: пузыри, аватары, ввод, вложения, поиск
│   ├── _support.scss       # поддержка, обращения, оценка качества
│   ├── _responsive.scss    # медиазапросы
│   └── styles.scss         # точка входа
├── css/styles.css        # скомпилированный CSS
├── js/main.js            # темы, уведомления, формы, вход, каталог, кнопки
└── js/chat.js            # чат, вложения, поиск, обращения, оценка
```

## Сборка CSS

```
npm install -g sass
sass scss/styles.scss css/styles.css
sass --watch scss/styles.scss:css/styles.css
```

## Где используется Flexbox

Шапка и нижняя панель (полосы на всю ширину, содержимое по общей сетке `.container`);
`.card-row` — ряд со скроллом; `.card-grid` — сетка 1/2/4 колонки; `.toolbar` и `.dropdown`;
формы (`.field`, `.alert`); `.menu-list` — пункты профиля на всю высоту экрана
(`flex-wrap` + `align-content: stretch`).
